# Code of Conduct

This project adopts the Contributor Covenant Code of Conduct, version 2.1, for all project spaces.

Canonical text: <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

## Expected behavior

Participants are expected to:

- Be respectful and constructive in issues, pull requests, reviews, discussions, and security reports.
- Focus criticism on the work and the evidence, not on the person.
- Accept maintainer decisions about scope, risk, roadmap, and release readiness.
- Handle vulnerability reports, private review context, and security-sensitive evidence with care.

## Unacceptable behavior

Unacceptable behavior includes harassment, threats, personal attacks, discriminatory language, deliberate disruption, doxxing, or publishing private security details without authorization.

## Reporting

Report conduct concerns privately through the same maintainer contact path documented in [SECURITY.md](SECURITY.md). Do not open a public issue for a sensitive conduct or security matter.

## Enforcement

Maintainers may remove comments, close threads, limit participation, or block contributors when behavior violates this code of conduct or creates risk for project participants.

Enforcement decisions should be proportionate, documented privately when needed, and separated from technical disagreement.
